# Distortube

A chromium browser extention that makes youtube videos look like s##t! (but faster)

## Install

## METHOD 1
1. Download & extract code as .zip
2. Go to extensions tab
3. Enable developer mode
4. Press "Load unpacked"
5. Go to the extracted code and insert it to your Chromium browser
## METHOD 2
1. Download the .crx
2. Open it with your browser

## Notes

- Works better on older devices
- only works with chromium
